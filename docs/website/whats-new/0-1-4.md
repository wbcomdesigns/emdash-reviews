# What's new in 0.1.4

**Included in Free.** WB Reviews has no paid version.

Members can review, Delete removes for good, and the admin screens are tidier.

## For site owners

- **Settings has four tabs.** **Where**, **Approval**, **Who can review** and **Email**, each with its own **Save**.
- **Guest email shows only when it applies.** **Ask guests for an email** appears only when **Anyone** can review.
- **Waiting and Published open with numbers.** You see how many are waiting, how many were published this week, and the average rating.
- **Long reviews are cut short in the table.** Choose **Read** in the **Decide** menu to see the full text.
- **Delete by email is tucked away.** It sits in an accordion at the bottom of **Published**.
- **A simpler dashboard card.** It shows the waiting count and an **Open Waiting** link.

## Fixed

- **Signed-in members can review.** Members write as their account, with no name field. On **Signed-in members only**, guests see a sign-in link that brings them back to the page.
- **Delete removes a review for good.** It asks first and updates the average at once. Before, it only hid the review.
- **Approve, Reject and Delete work on an opened review.** Choosing **Read** and then a button now acts on that review.
- **The waiting-review email starts off.** Switch it on and add an address together. Switching it on without an address tells you so.
- **Tags typed in a review are stored as plain text,** so a review never shows code like `<b>`.
- **Clearer stars and spacing.** Stars are outlines until chosen. Review cards and your reply have even spacing on any theme.
- **Readable on every light or dark choice.** Review text stays readable when a visitor picks your site's light mode on a device set to dark.

Copy the site kit again after you update. See [Install](../getting-started/install.md).
