# What's new in 0.3.0

**Included in Free.** WB Reviews has no paid version.

- **Built for Cloudflare's request limit.** On Cloudflare Workers, EmDash gives each plugin request 10 requests to the site. Every page, admin action and visitor request in WB Reviews now stays within that. Checking on a live Cloudflare site is still in progress, so the install guide still says Cloudflare is not supported yet.
- **Counts move with each review.** Writing, approving, rejecting or deleting a review updates the page's rating and the site's totals in the same request. Two reviews sent at the same moment are each counted once: a write that loses the race stores nothing and is asked to try again in a moment.
- **Faster lists.** Waiting and Published show 25 reviews at a time with Next and Previous. Find searches a few hundred reviews per press; **Search older** carries on from there.
- **Badges follow the page.** A rating badge hides as soon as its page is unpublished or deleted, and shows again when it is published.
- **Reviews sent early are kept.** On a slow first load, a review sent before the page has finished loading is held and sent as soon as it has.
- **Large erasures in steps.** **Delete all my reviews** removes up to 300 reviews per request and repeats until none are left. **Delete a guest's reviews by email** first clears that guest's waiting changes, then removes 100 reviews per press, and tells you when more remain.

## After you update

Open **Reviews, Waiting**. The first visits bring your 0.2 data over: they count the site, store page titles and rebuild every page's rating, including ratings an earlier version lost. Waiting and Published work as usual meanwhile, with **Updating your reviews for this version** on top; press **Continue** to speed it up. It also carries on by itself once an hour. Visitors keep seeing reviews and ratings on each page meanwhile; rating badges on post cards come back as each page's rating is rebuilt, so a page unpublished since 0.2 never shows one.

Copy the site kit again after you update: run step 2 of the [install guide](../getting-started/install.md) with the new tag.
