# What's new in 0.3.1

**Included in Free.** WB Reviews has no paid version. No new permission. The site kit is unchanged.

- **Setup errors no longer switch the plugin off.** On EmDash 1.5 an error in a plugin's install or activate step leaves it disabled. WB Reviews now logs the error and keeps running; deactivate and activate it again to retry.
- **Restored pages wait for publishing.** EmDash restores a trashed page as a draft, so its rating badge stays hidden until you publish the page again.
- **Lowest EmDash version stated.** The registry now checks that your site runs EmDash 1.2.0 or later before it installs WB Reviews.

The site kit files are the same as 0.3.0. If you copy them again, use tag `v0.3.1` in step 2 of the [install guide](../getting-started/install.md).
