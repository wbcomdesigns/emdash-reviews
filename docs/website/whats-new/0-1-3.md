# What's new in 0.1.3

**Included in Free.** WB Reviews has no paid version.

A fix release from a full walk on a test site, as a visitor and as an owner.

## For site owners

- **Star-only pages no longer say "Be the first to review this".** When a page has ratings but no written reviews, it says so.
- **A review without a rating is refused.** The visitor sees "Choose a rating." and a guest no longer gets a sign-in error first.
- **Signed-in members only now shows a sign-in link.** The form is replaced by the link.
- **The Waiting table keeps the Decide column on screen.** A very long word no longer pushes it off.
- **Delete by email.** The privacy erase for guests is find-by-email on **Published**. A "My reviews" page for members stays planned for 0.2.0.

## For visitors

- Review cards keep the same spacing inside a blog theme.

## For developers

- Copy the site kit again after updating.
