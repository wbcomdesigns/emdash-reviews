# What's new in 0.2.0

**Included in Free.** WB Reviews has no paid version.

- **My reviews.** Add `/account/reviews/` to your menu. A signed-in member sees every review they wrote, with its status, and can delete them all with a second click. Ratings update at once.
- **Reviews inside post text.** Optional Reviews and Rating blocks let you place the reviews or the star rating in the middle of a post. They need the trusted install described in the setup guide. The registry plugin works without them.
- **Safer server calls.** The shared kit file now runs server-side plugin calls inside EmDash, with no web request.

Copy the site kit again after you update.
