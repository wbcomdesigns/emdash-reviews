# What's new in 0.2.1

**Included in Free.** WB Reviews has no paid version.

- **Guests need a visitor address.** Guests can review only where your host passes EmDash the visitor's address: Cloudflare, or `trustedProxyHeaders` in `astro.config.mjs`. Elsewhere guests see a sign-in link and members review as normal. Settings tells you which applies. See [Guests and hosting](../getting-started/install.md#guests-and-hosting).
- **Waiting reviews never hide published ones.** The review list and the rating read only published reviews, however many are waiting, and pages with more than 500 reviews count them all.
- **Set up visitor pages.** The Waiting screen shows the command that copies the kit for your installed version, until you choose **Visitor pages are set up**.
- **One command for the kit.** `scripts/add-to-site.sh` copies the kit and prints the exact lines to paste, with the file names and the import paths that work from them.
- **Email without a provider.** Settings says plainly when the site has no email provider, and saving the Email tab sends one test notice.
- **My reviews.** The page uses your site's own column and side gutter, and a guest sees a plain sign-in prompt instead of a red error.

Copy the site kit again after you update: run step 2 of the [install guide](../getting-started/install.md) with the new tag.
